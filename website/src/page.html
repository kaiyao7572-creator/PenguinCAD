Open-source CAD for Linux · early · looking for help

A Fusion-style CAD for Linux, half‑built in the open.

PenguinCAD copies the way Fusion 360 works (the feature timeline, the marking menu, the shortcut keys) on OpenCASCADE, the open kernel FreeCAD also uses. Today you can sketch, extrude, fillet, drive it all from parameters and save your design. You can't make assemblies or drawings yet, and much of it is rough. If you want this to exist, the quickest way to get there is to help build it.

  1. A stray scrollbar. The ribbon grows a horizontal scrollbar under its buttons that Fusion doesn't have.
  2. Clipped fields. The properties panel cuts off its own values: "nm" is really "mm".

  4. A bare timeline. Fusion's has feature icons and a marker you drag. Ours is text buttons.

Install

Install it once, and it keeps itself up to date.

PenguinCAD ships as a Flatpak, so it runs the same on Fedora, Ubuntu, Arch, Mint or anything else with Flatpak. Remember what it is: an early build, for trying out and for helping, not yet for work you need to keep.

  1. Download the installer file A small .flatpakref file that tells your system where PenguinCAD lives. For 64-bit PCs (x86-64). Get penguincad.flatpakref
  2. Open it Double-click the downloaded file. GNOME Software or KDE Discover asks to install PenguinCAD. It adds PenguinCAD's own signed repository, so updates arrive like any other app's, and fetches the Qt runtime from Flathub.
  3. Search for “PenguinCAD” It's in your app grid and launcher like any other application, and in your software centre's search from now on.
# Everything in one line: installs Flatpak if you don't have it, # adds Flathub, then installs PenguinCAD.
curl -fsSL https://kaiyao7572-creator.github.io/PenguinCAD/install.sh | sh
# Already have Flatpak? This is all it does for PenguinCAD:
flatpak install --user https://kaiyao7572-creator.github.io/PenguinCAD/penguincad.flatpakref
# Updates come with everything else: flatpak update

Rather have the whole app in one file? Download the .flatpak (about 22 MB, x86-64) and double-click it; it updates from the same repository. Installed 0.1.0 from a downloaded file? That version can't update itself: run flatpak uninstall --user io.github.kaiyao7572_creator.PenguinCAD//master once, then install as above. Every version is on the releases page, and getting PenguinCAD onto Flathub itself is one of the open jobs.

Why this exists

Why build another CAD?

Fusion 360 taught a lot of people CAD: the timeline you can roll back, the ring of commands under the right mouse button, E for extrude. It doesn't run on Linux, and it keeps your designs in Autodesk's cloud.

The open-source options are real and some are excellent. None of them work the way Fusion does, and for someone who already knows Fusion, relearning a workflow is the hard part of switching.

PenguinCAD's bet is narrow: keep Fusion's interaction model as exactly as possible, on an open kernel, as a native Linux app. It is a long way from that goal. The table on the right is where we'd send you today, and it isn't mostly us.

  • A mature open-source CAD, todayFreeCAD
  • Fusion itself, on Windows or macOSFusion 360
  • Professional CAD in a browser, any OSOnshape
  • Parts written as code, reproducibleCadQuery · build123d · OpenSCAD
  • Small, fast constraint modelling on LinuxSolveSpace · Dune 3D
  • Fusion's way of working, native on Linux, open sourceNothing yet. That's the gap.

Where it stands

What works, what's being built, what nobody has started.

Works today

tested
  • Sketching: lines, rectangles, circles, arcs, polygons, slots, splines, conics
  • 12 constraints and 6 driving dimensions, on an in-house solver
  • Extrude, revolve, sweep, loft, as a new body or join, cut or intersect
  • Fillet, chamfer and shell (on every edge, for now)
  • Patterns, mirror, combine, Press Pull
  • Parameters and expressions with unit checking; every dimension is a d# name
  • Marking menu with click, flick and hold; Fusion's navigation and keys
  • Measure, section view, model properties
  • STEP import and export; STL and OBJ export

Just landed

new
  • Saving and opening designs: a native, human-readable .pcad format, with a round-trip test for every one of the 23 feature types
  • A real icon set: about a hundred SVG icons in place of the emoji
  • A Flatpak you can download and double-click to install

Not started: wanted

yours?
  • Assemblies and joints
  • 2D drawings a workshop can build from
  • Picking edges for fillet and chamfer
  • A Hole command
  • Sketching on construction planes
  • Sweeps along open paths
  • A Flathub listing, so it installs from GNOME Software and Discover
  • More packages: AppImage, AUR, COPR
  • Running the test suites in CI
  • Native Wayland (it runs through XWayland)
  • CAM

Questions

Fair questions.

Can I do real work in it?

Not yet. It can save and reopen a design now, but there are no assemblies or drawings, and plenty of rough edges. Treat it as something to build on, not something to depend on. If you need a CAD tool for a project this month, use one from the comparison above.

Why not contribute to FreeCAD instead?

That's a reasonable choice, and FreeCAD is the better tool today. Fusion's feel isn't a theme you can put on top of another program, though. It lives in the selection model, the timeline and the way every command flows, all the way down.

PenguinCAD is a small codebase where that feel is the whole design rather than an option. If you'd rather make FreeCAD more Fusion-like, that's good work too.

Was this written with AI?

Largely, yes, with Claude Code, and the commits say so. That's part of why it needs people: review from someone who knows the code, testing from someone who does CAD every day, and design judgment are exactly what it's short of.

Will it run on Windows or macOS?

Qt and OpenCASCADE both run there, so nothing fundamental stands in the way, but nobody has tried. It is developed on Fedora and only tested on Linux.

Is this affiliated with Autodesk?

No. It's an independent open-source project that imitates how Fusion 360 feels to use. It shares no code with it.

Build from source

Or build it: three commands on Fedora.

PenguinCAD needs Qt 6 and OpenCASCADE 7.8 or newer. Fedora packages both. On other distributions, making this easy is one of the open jobs above.

sudo dnf install opencascade-devel qt6-qtbase-devel cmake gcc-c++ git
git clone https://github.com/kaiyao7572-creator/PenguinCAD.git && cd PenguinCAD
cmake -B build && cmake --build build -j$(nproc) && ./build/penguincad
Then ./tests/run_tests.sh to check everything still passes.
# Install your distribution's Qt 6 base and OpenCASCADE (7.8+) development # packages, or build OCCT from source. Then:
git clone https://github.com/kaiyao7572-creator/PenguinCAD.git && cd PenguinCAD
cmake -B build -DOpenCASCADE_DIR=/path/to/occt/lib/cmake/opencascade
cmake --build build -j$(nproc) && ./build/penguincad
# The test runner still assumes Fedora's paths; fixing that is a good first issue.
