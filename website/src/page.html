A CAD app for Linux that works like Fusion 360.

Hi! I'm building PenguinCAD: a free, open-source CAD program that works the way Fusion 360 does. It has the timeline, the right-click menu and the same shortcut keys. You can already sketch, extrude, fillet, use parameters and save your work. There are no assemblies or drawings yet, and it's rough in places. I'd love for you to try it, and even more to help build it.

Install

It's a Flatpak, so it runs on pretty much any Linux distro, and it updates itself. It's an early version, though, so don't trust it with anything important yet.

  1. Download the installer file A small .flatpakref file that tells your system where PenguinCAD lives. For 64-bit PCs (x86-64). Get penguincad.flatpakref
  2. Open it Double-click the downloaded file. GNOME Software or KDE Discover asks to install PenguinCAD. It adds PenguinCAD's own signed repository, so updates arrive like any other app's, and fetches the Qt runtime from Flathub.
  3. Search for “PenguinCAD” It's in your app grid and launcher like any other application, and in your software centre's search from now on.
# Everything in one line: installs Flatpak if you don't have it, # adds Flathub, then installs PenguinCAD.
curl -fsSL https://kaiyao7572-creator.github.io/PenguinCAD/install.sh | sh
# Already have Flatpak? This is all it does for PenguinCAD:
flatpak install --user https://kaiyao7572-creator.github.io/PenguinCAD/penguincad.flatpakref
# Updates come with everything else: flatpak update

Rather have the whole app in one file? Download the .flatpak (about 22 MB, x86-64) and double-click it; it updates from the same repository. Installed 0.1.0 from a downloaded file? That version can't update itself: run flatpak uninstall --user io.github.kaiyao7572_creator.PenguinCAD//master once, then install as above. Every version is on the releases page, and getting PenguinCAD onto Flathub itself is one of the open jobs.

What works (and what doesn't yet)

Works now

  • Sketching: lines, rectangles, circles, arcs, polygons, slots, splines
  • Constraints and dimensions that actually drive the sketch
  • Extrude, revolve, sweep and loft, as new bodies or cutting and joining
  • Fillet, chamfer and shell (they apply to every edge for now)
  • Patterns, mirror, combine and Press Pull
  • Parameters: type an expression like d3 * 1.8 into any box
  • Saving and opening your designs
  • The right-click marking menu, Fusion's mouse controls and shortcuts
  • Measure, section view, STEP import/export, STL and OBJ export

Not yet

  • Assemblies and joints
  • 2D drawings
  • Picking which edges get filleted
  • A Hole tool
  • Sketching on construction planes
  • A Flathub listing
  • Mac and Windows (nobody has tried)
  • CAM

How it compares

Honestly, PenguinCAD does less than everything else on this list. If you need a CAD program for real work today, FreeCAD is the open-source one to get, and Fusion and Onshape are great if Windows, macOS or the cloud work for you. What I'm after is Fusion's way of working, running natively on Linux, and free.

Want to help?

Right now it's just me, so any help makes a real difference, and a lot of it doesn't need any code.

  • Try it and tell me what breaks. If you know Fusion, "Fusion does this differently" is super useful too. Open an issue
  • Fix one of the rough edges from the screenshot above. They're small Qt/C++ jobs and a nice way in.
  • Take on something bigger, like picked-edge fillets, a Hole tool, or eventually assemblies. Open an issue first so we can talk it through.
  • Package it for Flathub, the AUR or COPR, or add the tests to CI.
  • Design and docs: a light theme, a beginner tutorial, or better screenshots.

To get started with code: build it (see below), run ./tests/run_tests.sh, and skim docs/ARCHITECTURE.md. Then say on an issue what you're picking up. CONTRIBUTING.md has the full list.

Questions

Can I use it for real work?

Not yet. It saves and opens designs now, but there are no assemblies or drawings, and some parts are rough. Play with it, but use something else for anything you need to get done this month.

Why not just help FreeCAD instead?

Fair question, and FreeCAD is the better tool today. But Fusion's feel isn't a skin you can put on another program. It comes from how selection, the timeline and every command work together. I wanted a small codebase built around that from the start.

Was this written with AI?

A lot of it, yes. I use Claude Code, and the commits say so. That's a big part of why I want more people on it: reviews from someone who knows C++, testing from people who actually do CAD, and design taste.

Does it run on Windows or Mac?

Probably could, since Qt and OpenCASCADE both run there, but nobody has tried. It's built and tested on Linux.

Is this made by Autodesk?

No. It's an independent project that copies how Fusion 360 feels to use. It doesn't share any code with it.

Building from source

You need Qt 6 and OpenCASCADE 7.8 or newer. On Fedora that's one install line.

sudo dnf install opencascade-devel qt6-qtbase-devel cmake gcc-c++ git
git clone https://github.com/kaiyao7572-creator/PenguinCAD.git && cd PenguinCAD
cmake -B build && cmake --build build -j$(nproc) && ./build/penguincad
Then ./tests/run_tests.sh to check everything still passes.
# Install your distribution's Qt 6 base and OpenCASCADE (7.8+) development # packages, or build OCCT from source. Then:
git clone https://github.com/kaiyao7572-creator/PenguinCAD.git && cd PenguinCAD
cmake -B build -DOpenCASCADE_DIR=/path/to/occt/lib/cmake/opencascade
cmake --build build -j$(nproc) && ./build/penguincad
# The test runner still assumes Fedora's paths; fixing that is a good first issue.
